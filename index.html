03
Stage 03 · Courier

First rider wins

Nearby couriers get a 45-second full-screen alert — chime, haptics, countdown. One tap claims the trip.

  • 🔒 Distributed lock = zero double-assignment
  • 🧭 Native Maps navigation handoff
  • ✅ COD needs "I collected ৳X" confirmation
  • ⏳ Doorstep SOP: call ×2 → knock → 5-min countdown
45s dispatch alert
3-step guided trip
🔒 The 10-second lock: a Redis SET NX EX 10 picks the winner in milliseconds. A hundred couriers can tap at once — exactly one trip exists afterward.

WHY TEAMS PICK IT

Safe to bet the business on.

🔐 Security & reliability

  • ✓No passwords to leak — phone OTP, 2-min codes, 5-strike lockout
  • ✓Rotating tokens — 15-min access + reuse-detecting refresh
  • ✓Signed bank webhooks — replays & forgeries rejected
  • ✓Double-entry ledgers balancing to the penny
  • ✓600+ automated tests + an anti-cheat test guard, all in CI
  • ✓Off-site backups — 7-day retention, restore verified live

🎨 White-label in days

  • ✦One token spec — rebrand colors, type & radii per app
  • ✦Verticals are data — pharmacy-only or super-app, zero code
  • ✦Multi-currency — deterministic money, add any region
  • ✦EN · BN · AR (RTL) — new language = one file
  • ✦Own app identities — package, icon & splash per app
  • ✦Pluggable providers — swap gateways & SMS per market
