HOW A DELIVERY RUNS

One order, end to end.

Follow a single order across all four apps. A burger, a grocery basket or a pharmacy refill — the flow is identical for every vertical.

01 · Customer ordersDiscover, customize, guarded checkout

Stage 01 · Customer

The order is placed

Sign in with a 6-digit SMS code, pin the delivery location, and shop a feed sorted by true GPS distance.

  • 📍 Coverage-checked map pin
  • 🏷️ Coupon + full bill breakdown
  • 💳 COD or online payment
  • 🔒 Checkout locks itself if the store is closed or the order is below minimum

🧊 Frozen at checkout: address, variants & prices are copied onto the order — later menu edits can't rewrite a receipt. The coupon is claimed in the same DB transaction, so the last code can't sell twice.

Stage 02 · Outlet

The store prepares

The order lands as a loud, unmissable event — a synthesized bell rings every 3 seconds until someone acknowledges it.

  • 🔔 Zero-download chime loop
  • ⏱️ One-tap accept + prep countdown
  • 🧺 One-click sold-out toggles
  • ⏸️ Rush-hour pause when the counter is slammed

catalog & stock

🔊 Zero audio files: the chime is synthesized in-browser with the Web Audio API — nothing to fail on busy store Wi-Fi, and it only falls silent once every new order is acknowledged.
03
Stage 03 · Courier

First rider wins

Nearby couriers get a 45-second full-screen alert — chime, haptics, countdown. One tap claims the trip.

  • 🔒 Distributed lock = zero double-assignment
  • 🧭 Native Maps navigation handoff
  • ✅ COD needs "I collected the cash" confirmation
  • ⏳ Doorstep SOP: call ×2 → knock → 5-min countdown
45s dispatch alert
3-step guided trip
🔒 The 10-second lock: a Redis SET NX EX 10 picks the winner in milliseconds. A hundred couriers can tap at once — exactly one trip exists afterward.
04
Stage 04 · Customer

Watch it fly

From the sofa: the courier's position streams live onto the map, with a dashed planned route and a solid live leg.

  • 🛰️ Background GPS every ~10 m
  • 🪜 Six-stage timeline, real timestamps
  • 📞 One-tap call — courier or store
  • 🔁 Payment failed? One-tap switch to COD
Live courier radar
Immutable receipt
📡 Idle costs nothing: the tracking socket is reference-counted — connected only while an order runs or the screen is open, torn down otherwise. Nothing polls in the background.

Stage 05 · Finance

Every unit accounted for

Each delivery writes double-entry books: platform commission, outlet payout, courier pay — exact 2-decimal math in any currency.

  • 📊 Courier earnings today / this week
  • 🟠 COD cash meter: green → amber → red
  • 🏦 Hub deposit → admin verification
  • 🧾 Settlement cycles + accounting CSV

🔐 Safe by default

  • ✓No passwords to leak — phone OTP with rate limits and lockout
  • ✓Rotating tokens — a stolen refresh token kills its own session family
  • ✓Signed, idempotent payment webhooks — replays and forgeries rejected
  • ✓Double-entry ledgers balancing to the last decimal
  • ✓Fail-fast production boot — insecure settings refuse to start
  • ✓Automated off-site backups with verified restores
